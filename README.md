# 3D Gesture Particle System

Aplikasi interaktif partikel 3D berbasis gestur tangan menggunakan Python, OpenCV, MediaPipe, PyGame, dan PyOpenGL.

## 🖐️ Daftar Gestur Tangan:
- ✊ **0 Jari (Mengepal):** Bentuk Hati 3D (Heart)
- ☝️ **1 Jari (Telunjuk):** Planet Saturnus 3D
- ✌️ **2 Jari (Peace/V):** Teks 3D "I LOVE YOU"
- 🤟 **3 Jari:** Silinder / Tabung Partikel 3D
- ✋ **5 Jari (Terbuka):** Medan Bintang / Awan Partikel (Starfield)

## 🚀 Cara Menjalankan

> ⚠️ **Penting:** Disarankan menggunakan **Python 3.10 atau Python 3.11** (MediaPipe belum mendukung Python 3.14).

### 1. Install Library yang Dibutuhkan
Buka terminal/command prompt, lalu jalankan:
